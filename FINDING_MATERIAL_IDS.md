# 📚 How to Find Flashcard & Quiz IDs

## Quick Guide: Finding IDs for Materials

### **Step-by-Step: Where Are the IDs?**

#### **1. Navigate to Lectures**
```
Sidebar → Lectures
```

#### **2. Click Any Lecture**
```
Click on a lecture name to open it
```

#### **3. Look for Flashcards Section**
```
When the lecture opens, you'll see sections:
┌─────────────────────────────────┐
│ LECTURE: Biology Chapter 3      │
│                                 │
│ 📚 Flashcards (5)               │
│ ├─ Photosynthesis   ID: fc_abc1 │  ← COPY THIS ID
│ ├─ Mitochondria     ID: fc_abc2 │  ← COPY THIS ID
│ └─ Chloroplast      ID: fc_abc3 │  ← COPY THIS ID
│                                 │
│ ✓ Quizzes (2)                   │
│ ├─ Quiz 1           ID: qz_xyz1 │  ← COPY THIS ID
│ └─ Quiz 2           ID: qz_xyz2 │  ← COPY THIS ID
│                                 │
└─────────────────────────────────┘
```

#### **4. Copy the IDs**
Each flashcard and quiz has an ID like:
- Flashcards: `fc_ABC123`
- Quizzes: `qz_XYZ789`

## 📋 Adding Materials to Your Study Group

### **Complete Flow:**

```
1. Go to Study Groups → Your Group → [View]

2. Click [Add Materials] button

3. Select Material Type:
   - Flashcards OR Quizzes

4. Enter Set Name:
   "Chapter 3 Vocabulary"

5. (Optional) Add Description:
   "Important terms for midterm"

6. Go back to Lectures, copy IDs:
   fc_abc1
   fc_abc2
   fc_abc3

7. Paste IDs in modal (press Enter for each):
   Input field: fc_abc1 [ENTER]
   Input field: fc_abc2 [ENTER]
   Input field: fc_abc3 [ENTER]

8. Click [Add Materials]

9. ✅ All group members can now see these materials!
```

## 💡 Tips & Tricks

### **Finding IDs Quickly**
- **Look for colored badges** showing ID format
- **Copy button** (if available) copies the ID automatically
- **Hover over** flashcard/quiz cards to see full ID

### **ID Formats**
```
Flashcards:  fc_[random-chars]
Quizzes:     qz_[random-chars]
Format:      [type]_[unique-identifier]
```

### **Multiple Sets**
You can add materials from different lectures:
```
Lecture 1: Get IDs fc_a1, fc_a2, fc_a3
Lecture 2: Get IDs fc_b1, fc_b2
Lecture 3: Get IDs qz_c1, qz_c2

Add all to one group set:
Set Name: "Complete Biology Review"
Material IDs: fc_a1, fc_a2, fc_a3, fc_b1, fc_b2, qz_c1, qz_c2
✅ Mixed materials in one set!
```

### **Organizing Sets**
```
Bad: "Stuff"
Good: "Chapter 3-4 Key Terms"

Bad: "Quiz"
Good: "Practice Quizzes - First Half"

Bad: "More flashcards"
Good: "Vocabulary Set A - Definitions"
```

## ❓ Common Questions

### **Q: Can I add the same flashcard twice?**
A: The system prevents duplicates. If you add the same ID twice, the second one is ignored.

### **Q: Can I mix flashcards and quizzes?**
A: No. When adding materials, you select ONE type:
- Either all flashcards
- Or all quizzes
But you can create multiple sets mixing both.

### **Q: What if I can't find the ID?**
A: Make sure:
1. You're viewing the lecture (click [View])
2. The lecture has materials (sometimes empty lectures exist)
3. Look in the flashcard/quiz section specifically
4. If still not there, the lecture might not have generated materials yet

### **Q: Can group members add their own materials?**
A: Not yet. Only the group owner can add materials. Members can suggest materials by message (Phase 2).

### **Q: Can I remove a material I added?**
A: Yes! Group owner can click the red trash icon next to any material to remove it.

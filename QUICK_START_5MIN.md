# 🚀 GET STARTED IN 5 MINUTES

## Open http://localhost:5173

---

## 1️⃣ CREATE A STUDY GROUP (1 minute)

```
CLICK: Sidebar → Study Groups

CLICK: [+ New Group] button (purple, top right)

FILL IN:
├─ Group Name: "My Study Group"
└─ Description: "Let's study together"

CLICK: [Create] button

✅ DONE! Group created!
```

---

## 2️⃣ INVITE MEMBERS (1 minute)

```
CLICK: Your group name → [View]

CLICK: [Invite Member] button (purple)

ENTER:
├─ john@email.com + PRESS ENTER
├─ jane@email.com + PRESS ENTER
└─ bob@email.com + PRESS ENTER

CLICK: [Invite]

✅ DONE! Members invited! They'll see the group in their Study Groups.
```

---

## 3️⃣ ADD MATERIALS TO GROUP (1 minute)

```
CLICK: [Add Materials] button (blue)

SELECT: Flashcards OR Quizzes

FILL IN:
├─ Set Name: "Chapter 1 Notes"
└─ Description: "Important stuff" (optional)

GET IDs:
Go to Lectures → View flashcards/quizzes
Copy each ID

PASTE: Each ID in the modal + PRESS ENTER

CLICK: [Add Materials]

✅ DONE! Materials are now in your group! Members can see them!
```

---

## 4️⃣ SHARE YOUR CONTENT (1 minute)

```
OPTION A - MAKE PUBLIC:
├─ Go to any Lecture
├─ Click [Share] button (purple, top right)
├─ In modal, toggle [OFF] → [ON]
├─ Click [Copy] button
└─ Send link to anyone! (they don't need to login)

OPTION B - SHARE WITH SPECIFIC PEOPLE:
├─ Click [Share] button
├─ Click [Share with Users] tab
├─ Type email: jane@email.com
├─ Click [Add User]
├─ Close modal
└─ jane sees it in her "Shared with Me" page!
```

---

## 5️⃣ VIEW WHAT'S SHARED WITH YOU (1 minute)

```
CLICK: Sidebar → Shared with Me

SEE:
├─ Flashcard Sets shared with you
└─ Quiz Sets shared with you

CLICK: [View] to preview

CLICK: [Copy to Library] to own a copy

✅ DONE! Now you own that content!
```

---

## 🎯 MAIN BUTTONS SUMMARY

```
STUDY GROUPS PAGE
└─ [+ New Group] ...................... Create new group

GROUP DETAIL PAGE  
├─ [Invite Member] .................... Add members by email
├─ [Remove] (red buttons) ............. Remove members
├─ [Add Materials] .................... Add flashcards/quizzes
└─ [Delete] (red buttons) ............. Remove materials

LECTURE / STUDY / RESULTS PAGES
└─ [Share] (top-right) ............... Share content

SHARED WITH ME PAGE
├─ [View] ............................ Preview shared content
└─ [Copy to Library] ................. Own a copy
```

## 🆘 IF YOU CAN'T FIND SOMETHING

| Problem | Solution |
|---------|----------|
| "Where's the Invite button?" | Go to Group Detail Page, look top-right of Members section |
| "Where's the Share button?" | Go to Lecture/Study/Results page, look top-right of header |
| "How do I add flashcards?" | Click [Add Materials], paste flashcard IDs from your lectures |
| "Where do I see shared content?" | Sidebar → Shared with Me |
| "Can I remove someone?" | Yes, only if you're the owner, red button next to member name |
| "Can anyone access my public link?" | Yes, without login! Send the link anywhere |

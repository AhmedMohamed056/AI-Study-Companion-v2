### Step 4: How to Get Flashcard/Quiz IDs

**To Get Flashcard ID:**
```
1. Go to Lectures (sidebar → Lectures)
2. Click on any lecture
3. Scroll down to "Summary" section
4. Below summary, see "Flashcards" section
5. Each flashcard shows the ID (alphanumeric code)
6. Copy the ID from there
```

**To Get Quiz ID:**
```
1. Go to Lectures (sidebar → Lectures)
2. Click on any lecture
3. Scroll down to "Quizzes" section
4. See your quiz attempts with scores
5. Each quiz has an ID
6. Copy the quiz ID
```

### Step 5: Fill Materials Modal
```
Example Workflow:

1. Set Name: "Chapter 3 Vocabulary" ← Type this
2. Description: "Important words" ← Type this
3. Select: [Flashcards] ← Click this tab
4. Paste ID: fc_ABC123 ← Paste then press ENTER
5. Paste ID: fc_XYZ789 ← Paste then press ENTER
6. See both IDs in "Added IDs" list
7. Click [Add Materials] Button
```
